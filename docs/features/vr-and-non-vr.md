# VR and non-VR

VDXROVR has *optional* VR support; it supports the majority of consumer headsets.

For details, see [game compatibility](../compatibility/games.md)

## VR

VDXROVR will appear 'on your knee'. If it's in the wrong place, start by recentering instead of adjusting the position - it's useful to bind recentering VDXROVR to the same button/combination you use for recentering in-game.

You can add a recentering binding in VDXROVR Settings -> Input, or adjust the position in Settings -> VR.

If you fly with different aircraft or games, or switch between positions for another reason, you might want to use a different [profile](./profiles.md) for each game.

![VR Screenshot](../screenshots/theater.png)

## Non-VR

VDXROVR will appear in a fixed position in the game window; you can adjust the position in VDXROVR Settings -> Non VR. VDXROVR does not support an 'in-world' kneeboard position outside of VR, and this is unlikely to be added in the future.

You can hide/show VDXROVR with a 'toggle visibility' binding in VDXROVR -> Settings -> Input, or toggle, hide, or show with the [remote controls](./remote-controls.md), e.g. via a [StreamDeck](./streamdeck.md) or [VoiceAttack](./voice-attack.md).
